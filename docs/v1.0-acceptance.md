# v1.0 Cross-Platform Acceptance

Development branch: `v1.0-cross-platform`. This document records evidence, not
an announcement of Linux or Windows support.

## macOS Lifecycle Baseline - 2026-11-16

The initial baseline had three intermittent failures: Project start preflight,
group Service start, and persistent-runner recovery after TUI SIGKILL. All
three passed individually and in one unchanged full run, but repeating the
runner case reproduced a real defect:

- A control client can disappear before the runner accepts its connection.
  On macOS, setting a timeout on that disconnected socket can return EINVAL.
  Propagating that client error ended the runner and cleaned its managed group.
- The runner now discards a client whose socket cannot be configured, leaving
  the service and other clients alive. A regression test disconnects 32 clients,
  then verifies authenticated status, listener availability, and stop.
  The test failed with the old implementation.
- Local process inspection previously used unbounded `Command::output`.
  Shared bounded collection now limits individual `ps`, listener and working
  directory queries to five seconds and limits each output stream to 16 MiB.
  Queries run directly, without a shell wrapper. Timeout/overflow kills and
  reaps the inspection child; Project preflight reports the error and cancels
  the action rather than treating it as an empty process snapshot.
- Tests cover a blocked query, large stdout/stderr, nonzero exit, overflow,
  and monitor recovery after a failed inspection. The precise cause of the
  earlier two start-preflight timeouts was not captured; successful reruns
  alone are not proof of their cause.

Validation on the uncommitted macOS working tree:

- `LAZYTERM_SFTP_FIXTURE=1 cargo test --locked -- --test-threads=1`:
  296 unit/App tests and 9 CLI tests passed; 8 unit subprocess/native-store
  helpers and 1 CLI helper were ignored. The three original failures and real
  SSH/SFTP fixture passed. The separate password fixture was not enabled.
- Persistent TUI/runner SIGKILL recovery passed 12 consecutive invocations.
- Formatting, Clippy with all targets/features and warnings denied, and
  `git diff --check` passed.
- These results do not establish native Linux or Windows acceptance.
